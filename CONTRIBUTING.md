# Contributing

Thanks for helping out! Bug reports, fixes and small features are welcome.

## Setup

Follow the README (`./setup.sh`). You'll need a Mac, an iPad, a data-capable
USB cable, and an Apple developer team for signing the iPad app. Set your own
team ID in `ipad-client/project.yml` (`DEVELOPMENT_TEAM`) locally — please
don't include that change in a pull request.

## Pull requests

- Open an issue first for anything larger than a small fix.
- Keep changes focused; match the surrounding code style.
- Say how you tested it (device, iPad model, iOS / macOS version).
- `Info.plist` and the `.xcodeproj` are generated by `xcodegen` from
  `project.yml`; edit `project.yml`, not the generated files.
- CI runs `shellcheck` and a Python syntax check; run them locally if you can.
